☄️ 観測可能な彗星

データ源：NASA/JPL Small-Body Observability API + Horizons。
「今夜の彗星を取得」を押すと、その夜に観測可能な彗星を検索し、各彗星の一晩分の見かけ位置を取得してブラウザに保存します。 星図では時刻に合わせて位置を補間するため、地平線下から昇ってくる彗星も再現できます。
各彗星の「長期軌道を追う」を押すと、選択した彗星について観測日の30日前〜90日後を1日刻みで取得し、日付を変えても軌道と位置を追跡できます。

🗺 地図から観測地点を選択
NASA VIIRS 夜間光（2016年年次）を半透明表示。地上から見た空の明るさそのものではありません。
地図をクリック／タップして観測地点を選択してください。
