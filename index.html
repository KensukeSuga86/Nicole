☄️ 観測可能な彗星

データ源：NASA/JPL Small-Body Observability API + Horizons（Cloudflare Worker経由）。
「今夜の彗星を取得」を押すと、その夜に観測可能な彗星を検索し、各彗星の一晩分の見かけ位置を取得してブラウザに保存します。 星図では時刻に合わせて位置を補間するため、地平線下から昇ってくる彗星も再現できます。
各彗星の「長期軌道を追う」を押すと、選択した彗星について観測日の30日前〜90日後を1日刻みで取得し、日付を変えても軌道と位置を追跡できます。

プライバシー・位置情報について

Nicole the Astronavigator は、アカウント登録を必要とせず、アプリ本体に独自の広告トラッキングや行動解析機能を組み込んでいません。

「現在地を取得」を使用した場合、ブラウザから取得した緯度・経度は、星図や観測条件の計算に使用されます。天候、地点検索、標高、夜間光、彗星・流星群などオンライン機能を利用すると、観測地点や地図表示に伴う情報が、それぞれの外部サービスまたは Nicole の中継サーバーへ送信される場合があります。

お気に入り地点、表示設定、取得済みの一部データなどは、原則として利用中のブラウザの localStorage に保存されます。ブラウザのサイトデータを削除すると消去されます。

位置情報を外部へ送信したくない場合は「現在地を取得」を使わず、必要なオンライン機能を利用しないでください。ブラウザや各外部サービス側でアクセス記録等が保存される場合があります。

データ出典・外部サービス

  • 天候：Open-Meteo。Free API を利用する場合は同サービスの利用条件および CC BY 4.0 に従います。
  • 背景地図・標高：国土地理院・地理院タイル。地理院タイルおよび標高タイルを利用しています。
  • 地点検索：© OpenStreetMap contributors／Nominatim。
  • 夜間光：NASA Earthdata / GIBS、Suomi NPP/VIIRS Night Lights を参考表示します。
  • 彗星・軌道：独自データベース「星の鳥」と、必要に応じて NASA/JPL Horizons 由来の位置情報を利用します。
  • 星座線データ：hipparcos_planetarium_data_creator（GPLv2。Stellarium 由来データを含む）。
  • 天の川輪郭：d3-celestial およびその派生データ（d3-celestial は BSD-3-Clause）。
  • 地図表示ライブラリ：Leaflet 1.9.4。

各データ・サービスの著作権、ライセンス、利用条件はそれぞれの提供元に帰属します。提供元の変更・停止等により、一部機能が利用できなくなる場合があります。
