# Nicole Astronomy Database v0.2.0 補完・再検証レポート

## 目的
- v0.1.2 の未入力項目を可能な限り補完
- 科学データと説明を公的・天文学的資料に照らして再整理
- 神話・文化史を科学情報から分離し、異伝を単一事実として断定しない構造へ変更
- 宮沢賢治作品に直接登場する星座・恒星・天体を重点タグ化

## 結果
- 恒星: 64/64 に解説、64/64 に距離表示、英名 64/64
- Deep Sky: 119/119 に解説、119/119 に距離表示
- 星座: 88/88 に神話/成立史の検証メタデータ
- 宮沢賢治: 星座 10、恒星 4、Deep Sky 1 を直接タグ化

## 科学データの扱い
1. NASA Hubble Messier Catalog をMessierの主要一次参照に追加。
2. IAU/国立天文台を88星座の制度・名称の基準に追加。
3. SIMBAD/CDSを恒星の高精度照合先として明記。
4. 恒星距離は一般向け表示のため丸めた値。高精度計算に使う値ではないことを `verification` に明記。
5. Deep Skyの位置角など、元資料にない数値は引き続き推測で埋めていない。
6. 惑星の `magnitude_v` は時刻で変わるため、固定値を「UI参照値」と明記。

## 神話の扱い
- 神話は `explanation.science` から明確に分離。
- 古典星座は「代表的な異伝の一つ」として扱い、唯一の正解とはしない。
- 近世以降の星座には、古代ギリシャ神話を後付けしない。
- `mythology.status / source_basis / editorial_note` を追加。

## 宮沢賢治重点項目

さそり座、わし座、こいぬ座、オリオン座、アンドロメダ座、おおぐま座、こぐま座を直接タグ化。

## 注意
この版は解説用途のデータベースです。恒星距離など研究級の高精度値が必要な場合は、SIMBAD/Gaia等を観測時点で直接照会してください。
