# Nicole the Astronavigator

**星空の案内人・ニコルと一緒に**

Nicole the Astronavigator は、天体観測の計画、観測中の星空確認、星空の解説をひとつにまとめた天体観測支援Webアプリです。

観測する日時と場所を設定すると、その場所から見える星空を計算し、星図、天体、星座、月齢、薄明、天候、彗星、流星群、撮影支援などをまとめて確認できます。

## Nicoleでできること

Nicoleは主に、次の3つの用途を想定しています。

1. **天体観測を計画する**
2. **今見えている星を確認する**
3. **星空について解説する**

名前を知らない星を調べたり、今夜見やすい天体を探したり、スマートフォンを空へ向けながら星図を追尾させたり、星景写真の撮影条件を考えたりできます。

## 主な機能

### 🔭 観測条件

観測日時と場所を指定して、その場所の星空を計算します。

- 現在地から観測開始
- 日時指定
- 緯度・経度・標高指定
- 地名・施設名・住所検索
- 地図から観測地点を選択
- お気に入り地点
- 月相から日付選択
- 現在時刻追従

現在地や地図から地点を選んだ場合、オンライン時には国土地理院の標高データから標高を取得します。

地図ではNASA GIBSのVIIRS Night Lightsを参考表示し、周辺のより暗い候補地点を探す機能もあります。

> 夜間光は空の明るさそのものを測定した値ではありません。また、道路状況、私有地、立入可否、安全性、視界などは判定しません。

## 🗺 星図

指定した日時・場所の星空を表示するNicoleの中心機能です。星図パネルを含む主要な折りたたみパネルは初期状態では閉じています。

### 3つの表示モード

- **全天**  
  天頂を中心に地平線までを円形表示します。

- **地平**  
  実際に空を見上げる感覚に近い方向表示です。ドラッグ / スワイプで視線方向を変更できます。

- **📱追尾**  
  スマートフォンの方位・傾きセンサーを使い、端末を向けた方向へ星図を追尾します。

追尾モードでは、DeviceOrientation から端末背面の視線方向を算出して星図へ反映します。追尾全画面では「全画面終了」ボタンを画面右下へ配置します。 「今夜のおすすめ」や天体カードから対象を選択している場合は、画面外の対象方向を矢印で案内します。高仰角で方位が約180°飛ぶ端末に対しては、直前の視線方向との連続性を使った補正を行います。

v1.9.4では、スマートフォンを横向きにした際に方位が約90°ずれる問題を修正しました。端末姿勢から算出した視線ベクトルへ `screen.orientation.angle` を重ねて適用していた二重補正を廃止し、縦向き・横向きのどちらでも同じ実方位を維持するようにしています。

### 全画面表示

「⛶ 全画面」または「⛶ 追尾を全画面」を使用すると、**星図パネル全体ではなく、星空が描画されている星図だけ**を全画面表示します。

地平・追尾モードでスマートフォンを横向きにすると、単純な横方向への引き伸ばしではなく、縦方向の見え方を保ったまま**左右の視野を広げて表示**します。

v1.10.0では縦向き全画面でも地平・追尾モードが画面高を使うようになり、上下の余白を減らしました。

全天表示は地平円を保つため円形表示のままです。

### 表示できるもの

- 星座線
- 星座名
- 星の目印
- 天の川
- 太陽
- 黄道
- 昼光
- 月
- 白道
- 月光
- 惑星
- 主要天体
- 彗星
- 流星群放射点
- 恒星の等級上限
- 撮影写野
- 選択彗星の長期軌道

星、惑星、月、主要天体、彗星、流星群放射点などは、タップして情報を確認できます。「星図で表示 / 星図で見る」で選択した対象は星図パネルの「✕ 選択解除」で解除できます。

- 月の出 / 月の入り

## ☁️ 天候

Open-Meteoから観測地点の天候予報を取得します。

- 総雲量
- 低層雲
- 中層雲
- 高層雲
- 降水確率
- 降水量
- 気温
- 湿度
- 風速
- 視程

雲量については、以下の予報モデルも比較します。

- JMA MSM
- ECMWF IFS
- NOAA GFS

同じ地点では通常予報を30分、予報モデル比較を2時間を目安に再利用し、不要な通信を減らします。

## 📷 撮影支援

星景写真や星空タイムラプスの撮影を支援します。

### 写野・カメラ

- Nikon Z8
- Nikon D6
- Nikon ZR
- カスタムカメラ

焦点距離とカメラの向きを指定し、撮影写野を星図上へ表示できます。

カスタムカメラではフルサイズ、APS-C、フォーサーズからセンサーサイズを選び、画素数を登録できます。

### 星を点で写す

画素ピッチ、焦点距離、撮影方向から日周運動による星像の移動量を見積もり、推奨シャッタースピードを計算します。

- 星像優先：1.5 px以内を目安
- 実用優先：2.5 px以内を目安
- NPF参考
- 500ルール参考
- 焦点距離別推奨SS比較

### 連続撮影・合成

- インターバル撮影時間
- タイムラプス必要枚数
- 比較明合成 / 星グル
- 総撮影時間 → 必要枚数
- スタッキングによる理論S/N改善

天の川・銀河中心の状態や、月明かり、月との角距離も確認できます。

## 🧭 赤道儀

観測日時・緯度・経度から北極星の位置を計算し、時計盤形式のレクチルへ表示します。

- 北極星 時計位置
- 北極星 時角
- 極軸高度の目安
- 観測地点標高
- レクチル反転

極軸望遠鏡の実際の像の向きやレクチル仕様は機種・世代によって異なるため、使用機材の仕様と合わせて利用してください。

## ✦ 天体

設定した観測条件で見える天体をカード形式で表示します。

- 種類で絞り込み
- おすすめ順
- 高度順
- 明るさ順
- 難易度順

各天体では、データ、解説、18時〜翌6時の高度グラフなどを確認できます。

「星図で見る」で対象天体を星図上へ表示し、「いつ・どこで見る？」から別日時・別地点を探せます。

---

## ✨ 星座

観測日時・場所で見えている星座を表示します。

星座名・英語名だけでなく、科学・神話・由来のキーワードから検索できます。

各星座の解説は、

- **科学**
- **神話・由来**

を分けて表示します。

「星図で見る」で対象星座を強調表示できます。

---

日付を選ぶと、

- 月相

などを確認できます。

## ⌚️ 観測スケジュール

観測可能な天体を時間帯に割り当てた一覧です。

- 推奨時間
- 種類
- 難易度
- 高度
- 方位
- 推奨倍率
- 見どころ

## 🔎 いつ・どこで見る？

天体や星座を基準に、

**「これを見るなら、いつ・どの場所がよいか」**

を探す逆引き観測計画機能です。

現在地点とお気に入り地点を対象に、

- 今後7日
- 今後30日
- 今後90日
- 最低高度10° / 20° / 30° / 40°

などの条件で候補を検索します。

夜の暗さや月の状態も考慮して候補日時を表示します。

## 🧹 彗星

### 星の鳥

独自の彗星軌道データベース **「星の鳥」** から彗星を検索します。

彗星名、符号、SPK-IDなどを利用できます。

計算モード：

- 簡易計算
- 精密計算
- JPL高精度

選択した彗星は星図へ表示でき、JPLを利用した長期軌道表示にも対応しています。

### 今夜の彗星

NASA/JPLから、指定した観測地点で今夜観測可能な彗星を取得します。

一晩分の位置を15分刻みで取得し、星図時刻に合わせて補間します。

長期軌道では、観測日の30日前〜90日後を1日刻みで取得できます。

## Nicole Cache Manager

PWAの動的キャッシュが無制限に増えないよう、種類ごとに有効期限と件数上限を設定しています。

| データ | 保持目安 | 件数上限 |
|---|---:|---:|
| 天候 | 18時間 | 64件 |
| 彗星系 | 7日 | 160件 |
| 流星群 | 45日 | 16件 |
| 星の鳥 | 365日 | 240件 |
| 星座線・天の川など固定天文データ | 365日 | 32件 |
| 動的データキャッシュ全体 | - | 320件 |

期限切れデータはオフライン時にも使用しません。

旧バージョン用のアプリキャッシュも、新しいService Workerの有効化時に整理します。

## データ・外部サービス

Nicoleでは機能に応じて、以下のデータ・サービスを利用します。

- **天候**：Open-Meteo
- **背景地図・標高**：国土地理院
- **地点検索**：OpenStreetMap / Nominatim
- **夜間光**：NASA Earthdata / GIBS / VIIRS Night Lights
- **彗星・軌道**：「星の鳥」、NASA/JPL
- **流星群**：International Meteor Organization（IMO）

基本的な天文計算はNicole内の計算エンジンで行っています。

詳細な出典、プライバシー、免責事項は、アプリ内の **「ⓘ データ出典・プライバシー・免責事項」** を確認してください。

## プライバシー

お気に入り地点、表示設定、取得済みデータの一部などは、原則として利用中のブラウザ内に保存されます。

端末連動を使用する場合、ブラウザの方位・傾きセンサーを星図の表示方向に利用します。Nicoleはセンサー値を独自サーバーへ送信する処理を行いません。

オンライン機能を利用した場合は、利用する外部サービスへ必要なリクエストが送信されます。

## 使い方

アプリ右上またはフッターの **「📖 使い方」** から、Nicoleに組み込まれた最新の使用マニュアルを開けます。

観測現場では、まず次の流れがおすすめです。

1. 現在地なら「現在地で観測する🔭」を使用
2. 「空の情報」と天候を確認
3. 「星図」を開き、全天表示で空全体を把握
4. 実際の空と見比べるなら「地平」
5. スマートフォンを空へ向けるなら「📱追尾」
6. 必要に応じて星図を全画面表示
7. 横向きにすると地平 / 追尾では左右の視野が広がる
8. 気になる天体をタップして詳細を確認
